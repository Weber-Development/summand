# UN/CEFACT Cross Industry Invoice D16B schemas

Files in this folder are unchanged copies of the UN/CEFACT Cross Industry Invoice schema
100.D16B, SCRDM subset with decoupled ("uncoupled") code lists, as used by EN 16931 and the
KoSIT validator configuration for XRechnung 3.0. Source:
https://github.com/ConnectingEurope/eInvoicing-EN16931, tag validation-1.3.16
(commit a519ba02a59e2775436428f57ee96899feb1da8c),
`cii/schema/D16B SCRDM (Subset)/uncoupled clm/CII/uncefact/data/standard/`.
